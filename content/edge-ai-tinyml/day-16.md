## What I Explored Today

Today I built a complete TinyML pipeline for vibration anomaly detection using a 3-axis accelerometer on a Cortex-M4 board. The goal was to detect when a motor bearing transitions from normal operation to a failing state, using only on-device inference. I used an autoencoder trained on normal vibration patterns, quantized to int8, and deployed via TensorFlow Lite Micro. The model runs at 20ms per inference window, consuming 12kB of RAM and 48kB of flash.

## The Core Concept

Vibration anomaly detection is fundamentally about learning the "normal" distribution of accelerometer signals and flagging deviations. The key insight: you don't need labeled fault data. In industrial settings, you have abundant normal data and almost no failure data. An autoencoder solves this by learning to reconstruct normal vibration patterns with low error. When a new pattern arrives, if the reconstruction error exceeds a threshold, you have an anomaly.

Why TinyML matters here: industrial vibration sensors often run on battery or energy-harvesting power. Streaming raw 3-axis data at 1kHz to the cloud burns through power and bandwidth. Running inference locally means you only transmit alerts—a 10-byte message instead of megabytes per hour. The trade-off is you need a model small enough to fit in microcontroller SRAM, typically 64-256kB.

The math is straightforward: your accelerometer outputs (x, y, z) at some sample rate. You window these into frames (e.g., 128 samples per axis = 384 values). The autoencoder compresses this to a latent space of 8-16 floats, then reconstructs. Anomaly score = mean squared error between input and reconstruction. If score > threshold (set during calibration on normal data), flag anomaly.

## Key Commands / Configuration / Code

Here's the deployment code for the STM32L4 using TensorFlow Lite Micro. This assumes you've already trained and quantized your autoencoder model to int8.

```c
// vibration_anomaly.h - inference header
#include "tensorflow/lite/micro/all_ops_resolver.h"
#include "tensorflow/lite/micro/micro_interpreter.h"
#include "tensorflow/lite/schema/schema_generated.h"

// Model buffer - generated by xxd from .tflite
extern const unsigned char g_autoencoder_model[];
extern const int g_autoencoder_model_len;

// Inference state
static tflite::MicroMutableOpResolver<10> resolver;
static tflite::MicroInterpreter* interpreter;
static float anomaly_threshold = 0.045f;  // tuned on calibration data

// Buffer for input/output tensors
constexpr int kTensorArenaSize = 48 * 1024;  // 48kB arena
static uint8_t tensor_arena[kTensorArenaSize];

// Initialize the interpreter once
void anomaly_init() {
    // Map model into flatbuffer
    const tflite::Model* model = tflite::GetModel(g_autoencoder_model);
    
    // Add only needed ops to reduce flash usage
    resolver.AddFullyConnected();
    resolver.AddRelu();
    resolver.AddQuantize();
    resolver.AddDequantize();
    
    // Create interpreter
    static tflite::MicroInterpreter static_interpreter(
        model, resolver, tensor_arena, kTensorArenaSize);
    interpreter = &static_interpreter;
    
    // Allocate tensors
    TfLiteStatus allocate_status = interpreter->AllocateTensors();
    if (allocate_status != kTfLiteOk) {
        // Handle error - flash LED, log, etc.
    }
}

// Run inference on one window of accelerometer data
// input_data: 128 samples per axis, interleaved [x0,y0,z0,x1,y1,z1,...]
// returns: anomaly score (MSE between input and reconstruction)
float detect_anomaly(int16_t* input_data, size_t num_samples) {
    // Get input tensor (expects int8 quantized)
    TfLiteTensor* input = interpreter->input(0);
    int8_t* quantized_input = tflite::GetTensorData<int8_t>(input);
    
    // Quantize int16 accelerometer data to int8 model input
    // Scale factor from training: input_scale = 0.007843, zero_point = -128
    const float input_scale = 0.007843f;
    const int input_zero_point = -128;
    
    for (size_t i = 0; i < num_samples; i++) {
        float normalized = (float)input_data[i] / 2048.0f;  // ±2g range
        int32_t quantized = (int32_t)(normalized / input_scale) + input_zero_point;
        quantized_input[i] = (int8_t)CLAMP(quantized, -128, 127);
    }
    
    // Run inference
    TfLiteStatus invoke_status = interpreter->Invoke();
    if (invoke_status != kTfLiteOk) {
        return -1.0f;  // error sentinel
    }
    
    // Get output tensor (reconstructed signal)
    TfLiteTensor* output = interpreter->output(0);
    int8_t* quantized_output = tflite::GetTensorData<int8_t>(output);
    const float output_scale = 0.007843f;
    const int output_zero_point = -128;
    
    // Compute MSE between input and reconstruction
    float mse = 0.0f;
    for (size_t i = 0; i < num_samples; i++) {
        float original = (float)input_data[i] / 2048.0f;
        float reconstructed = (float)(quantized_output[i] - output_zero_point) * output_scale;
        float diff = original - reconstructed;
        mse += diff * diff;
    }
    mse /= (float)num_samples;
    
    return mse;
}

// Main loop usage
void main_loop() {
    int16_t buffer[384];  // 128 * 3 axes
    while(1) {
        fill_accel_buffer(buffer, 128);  // blocking read
        float score = detect_anomaly(buffer, 384);
        
        if (score > anomaly_threshold) {
            send_alert("ANOMALY_DETECTED", score);
            // Optional: log raw data for later analysis
        }
        // else: normal operation, no transmission
    }
}
```

Training script snippet (Python, using TensorFlow):

```python
# train_autoencoder.py
import tensorflow as tf
from tensorflow import keras

# Load normal vibration data (3-axis, 128-sample windows)
X_train = load_normal_data()  # shape: (N, 384)

# Build autoencoder
input_dim = 384
latent_dim = 12

inputs = keras.Input(shape=(input_dim,))
encoded = keras.layers.Dense(64, activation='relu')(inputs)
encoded = keras.layers.Dense(latent_dim, activation='relu')(encoded)
decoded = keras.layers.Dense(64, activation='relu')(encoded)
outputs = keras.layers.Dense(input_dim, activation='linear')(decoded)

autoencoder = keras.Model(inputs, outputs)
autoencoder.compile(optimizer='adam', loss='mse')

# Train only on normal data
autoencoder.fit(X_train, X_train, epochs=50, batch_size=32, validation_split=0.1)

# Convert to TFLite with int8 quantization
converter = tf.lite.TFLiteConverter.from_keras_model(autoencoder)
converter.optimizations = [tf.lite.Optimize.DEFAULT]
converter.representative_dataset = representative_dataset  # calibration data
converter.target_spec.supported_ops = [tf.lite.OpsSet.TFLITE_BUILTINS_INT8]
tflite_model = converter.convert()

# Save for deployment
with open('autoencoder_quant.tflite', 'wb') as f:
    f.write(tflite_model)
```

## Common Pitfalls & Gotchas

**1. Quantization calibration mismatch.** Your representative dataset for int8 quantization must match the actual sensor range and noise floor. I once calibrated with data from a ±2g range, then deployed on a sensor set to ±4g. The model saw every sample as saturated and flagged everything as anomalous. Always verify your sensor configuration matches the calibration dataset's range and resolution.

**2. Threshold drift over temperature.** The reconstruction error threshold you set at 25°C may fail at 85°C because accelerometer bias drifts. I've seen normal vibration MSE increase by 3x over temperature. Solution: either temperature-compensate the threshold (simple lookup table) or use a dynamic threshold based on a running median of recent scores. The latter is more robust.

**3. Window alignment and phase.** If your 128-sample window doesn't align with the vibration period (e.g., 60Hz motor = 16.67ms period at 1kHz sampling), you'll get high reconstruction error on perfectly normal data because the autoencoder sees a partial cycle. Always test with a sine wave at your fundamental frequency first. I use a 256-sample window for 60Hz motors sampled at 1kHz—covers exactly 4 cycles.

## Try It Yourself

1. **Collect your own normal data.** Mount an accelerometer on a small DC motor running at constant speed. Record 10 minutes of 3-axis data at 1kHz. Train an autoencoder on 80% of the windows, validate on 20%. What MSE threshold gives <1% false positive rate?

2. **Inject a fault.** Tape a small nut or bolt to the motor shaft to simulate imbalance. Run inference on the fault data. How much does the MSE increase compared to normal? Plot the distribution of anomaly scores for normal vs. fault conditions.

3. **Optimize for memory.** Your current model uses 48kB arena. Try reducing the latent dimension from 12 to 8, or the hidden layer from 64 to 32 neurons. Retrain and measure the trade-off: how much does the anomaly score separation degrade? Can you still detect the nut fault with the smaller model?
